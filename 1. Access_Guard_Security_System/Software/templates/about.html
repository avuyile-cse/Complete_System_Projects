Access Guard is an IoT Based security system integrated with a secure web interface(Intranet-based). The system is designed to ensure that only authorized individuals gain access to protected premises where the system is deployed.

It combines hardware, networking, and web technologies to provide real-time monitoring and controlled access management.

Key Features:
  1. Secure user authentication and gated access control
  2. Real-time site monitoring
  3. Client registration and management
  4. Live system status update
