🚧 Access Guard Security System
---------------------------------

📌 **Project Overview**

Access Guard Security System is an IoT-Based security solution that integrates hardware and software components to provide
intelligent monitoring and controlled access to secured premises. This system ensures that only authorized users gain access
while enabling  real-time monitoring and remote administrative control.

:moProject motivation
Portfolio Development - Demostrating integration of networking, backend development, database systesms, and embedded hardware
communication.

💻 **System Architecture - Core Components**

- Web-based  User Interface
- Flask Application Server
- MySQL Database
- ESP8266 WIFI-module
- Microcontroller
- Electronic Circuitry
- Power BI (Data Visualization)
- Network Architecture

🦺 **Security Measures**

- User Authentication and Authorization
- Password hashing and encryption
- Router firewall rules and port control
- Network segmentation
- Secure communication protocols (HTTPS)
